# 📊 Oracle SQL Assignments Repository

This repository contains a collection of **Oracle SQL assignment solutions** covering various real-world database problems and concepts. It is structured for easy navigation, learning, and revision.

---

## 📁 Folder Structure

```
Oracle_sql/
│── Questions/        # Contains assignment questions
│── solutions/        # Contains SQL solutions
│── README.md         # Project documentation
```

---

## 📌 Contents

The repository includes solutions for:

* ✔️ Basic SQL Queries
* ✔️ Joins (Inner, Left, Right, Self Join)
* ✔️ Aggregate Functions
* ✔️ Subqueries & Correlated Subqueries
* ✔️ Window Functions (RANK, DENSE_RANK, etc.)
* ✔️ Data Filtering & Sorting
* ✔️ Real-world problem-solving queries

## 🚀 How to Use

1. Clone the repository:

   ```bash
   git clone https://github.com/BrijeshShinde/Oracl_sql.git
   ```

2. Open the `.sql` files in:

   * Oracle SQL Developer
   * SQL*Plus
   * Any compatible SQL IDE

3. Run queries and analyze outputs.
